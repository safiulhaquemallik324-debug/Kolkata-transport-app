# 🚇 Kolkata Transport App

An AI-assisted smart transportation platform built to help people navigate Kolkata's public transport system with confidence. Whether you're a daily commuter or a first-time visitor, the app provides intelligent guidance for finding the right buses, metro routes, nearby stops, and travel information.

## 🎯 Project Vision

Many people feel confused or anxious when traveling to a new place. They often struggle to determine which bus or metro to take, where to get off, or how to reach their destination efficiently.

Kolkata Transport App was created to solve this problem by providing smart navigation assistance, AI-powered guidance, real-time information, and an intuitive user experience that helps users travel confidently throughout the city.
